## Develop

Requires PHP 8.2+, Composer and `ext-pdo_sqlite`. Dependencies install into each package's own `vendor/`.

```sh
sh adapters/php/scripts/prepare.sh   # packs the shared UI, runs composer install
sh adapters/php/scripts/test.sh      # PHPUnit for core, laravel and symfony
node tests/conformance/run.mjs php-laravel
node tests/conformance/run.mjs php-symfony
```

## Release packaging

The workbench UI in `core/resources/ui` is generated by `tools/pack-ui.mjs` and is **not tracked in git**, so a bare git tag would install without it. Build the distributable archives instead:

```sh
sh adapters/php/scripts/build-release.sh 0.1.0-alpha.1   # writes adapters/php/dist/testbench-{core,laravel,symfony}-<version>.zip
```

The script packs the UI, runs `composer archive` (each package's `archive.exclude` leaves out `vendor/`, tests and lockfiles) and fails if the core ZIP lacks `resources/ui/manifest.json` or any ZIP contains `vendor/` or `tests/`. Install the ZIPs through a Composer [`artifact` repository](https://getcomposer.org/doc/05-repositories.md#artifact), or publish them as release assets.
