## Develop

Requires PHP 8.2+, Composer and `ext-pdo_sqlite`. Dependencies install into each package's own `vendor/`.

```sh
sh adapters/php/scripts/prepare.sh   # packs the shared UI, runs composer install
sh adapters/php/scripts/test.sh      # PHPUnit for core, laravel and symfony
node tests/conformance/run.mjs php-laravel
node tests/conformance/run.mjs php-symfony
```

## Release packaging

The workbench UI in `core/resources/ui` is generated by `tools/pack-ui.mjs` and is **not tracked in git**, so a bare git tag would install without it. Packagist reads `composer.json` from a repository root, so each package is released to its own split (mirror) repository, and the mirror tree must contain the UI. Build those trees with the shared release driver:

```sh
node tools/pack-all.mjs --only packagist --verify   # writes artifacts/packages/packagist/testbench-{core,laravel,symfony}-<version>.zip
```

Each ZIP holds exactly the tree to commit to a mirror repository root: `composer.json` (siblings pinned to the release, repository and issue links stamped from `adapters/go/MODULE_PATH`, no path repositories or dev tooling), `LICENSE`, `README.md`, `src/` and, for core, `resources/ui`. The module (`tools/release/packagist.mjs`) validates each manifest with `composer validate --strict`, fails if a ZIP contains `vendor/` or `tests/`, and `--verify` installs the ZIPs through a Composer [`artifact` repository](https://getcomposer.org/doc/05-repositories.md#artifact) into a fresh Laravel app and serves `/bench/`. The ZIPs carry no `version`: Packagist takes versions from git tags.
