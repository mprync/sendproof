# Design Context — Sendproof

**Audience:** .NET developers, QA and support engineers exercising an API in Development or a hosted dev environment. Technical, keyboard-heavy, often on a laptop beside an IDE; sometimes on a phone or tablet checking a fix.

**Jobs:** find an operation fast; fill typed inputs without hand-writing JSON; see what a call *would* do (dry run, database diff) before committing it; act as a real user (any enabled sign-in method); copy the request into code.

**Personality:** calm, precise, quiet. Linear/Notion calibre. Professional, never elaborate. Content first; chrome recedes.

**Constraints:** WCAG 2.2 AA (contrast, focus visible, target size ≥ 24px, no colour-only meaning, reduced motion, landmarks). Works at 320px wide and at 200% text. Light and dark themes. Generated entirely from OpenAPI at build time — every screen must be expressible from schema data.
