## Track A

- **2026-11-20.** Implemented scoped structured logs, redacted EF Core command capture, timing, typed email/HTTP/job/message effects, and owner-only observed sends. Updated the protocol schemas, adapter docs and the example. Added regressions for capture isolation, host log levels, SQL redaction and opt-out, trace ownership and expiry, and capture bounds.
- Protocol v1 discovery adds optional `observedSend`. Send an advertised operation to its original URL with `Prefer: trace`. When the response contains `X-TestBench-Trace`, fetch `GET /bench/_api/traces/{id}` as that same authenticated subject. The trace contains `changes`, `effects`, `logs` and `timing: {auth, handler, db, queryCount, serialize}`. Durations are in milliseconds.
- Preview and trace may include `logsTruncated`, `effectsTruncated` and `changesTruncated`. Logs add optional `category`, `eventId: {id, name?}`, `offsetMs`, `elapsedMs`, `properties: {[name]: string}`, `exception: {type, message}` and `sql: {text, parameters: [{name, value, dbType}], rowsAffected?}`. SQL uses `level: "Sql"`. A redacted parameter value is `"[REDACTED]"`.
- Effects add optional `delivered: true` on observed Send. Conventional `data` fields are email `{from, to[], cc[], subject, text, html?}`, HTTP `{method, url, status?, body?}`, job `{name, queue?, runAt?, arguments}` and message `{topic, key?, payload}`. Both modes expose `Server-Timing` metrics `auth`, `handler`, `db` with `desc="N queries"`, and `serialize`.
